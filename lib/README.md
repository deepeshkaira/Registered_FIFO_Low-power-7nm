# ASAP7 libraries

Place the following compiled ASAP7 Liberty databases in `lib/asap7_db/` before running Design Compiler or PrimeTime:

- `asap7sc7p5t_AO_RVT_TT_08302018.db`
- `asap7sc7p5t_INVBUF_RVT_TT_08302018.db`
- `asap7sc7p5t_OA_RVT_TT_08302018.db`
- `asap7sc7p5t_SEQ_RVT_TT_08302018.db`
- `asap7sc7p5t_SIMPLE_RVT_TT_08302018.db`

The library files are not redistributed in this repository. The available databases use the `PVT_0P7V_25C` operating condition. Consequently, power and timing reported for the 0.6 V FIFO domain are architectural estimates rather than a fully characterized 0.6 V signoff result.
